# Sales Forecast AI

Pipeline-weighted sales forecasts, trend analysis, and quota attainment modeling for revenue teams.

## Features
- Pipeline-weighted forecast models per rep, team, and region
- Quota attainment probability scoring
- Trend and seasonality detection on bookings history
- Forecast-vs-actual drift alerts
